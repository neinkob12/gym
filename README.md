# Gym Tycoon

Handyspiel: Du erbst die heruntergekommene Muckibude deines Onkels und machst daraus das beste Gym der Stadt.
Low-Poly-3D, isometrisch, Hochformat, Idle-Tycoon.

Status: **Planung** (Etappe E0).

`prototypes/3d/index.html` im Browser öffnen (braucht Internet für Three.js). Ziehen zum Verschieben, zwei Finger oder Mausrad zum Zoomen,
