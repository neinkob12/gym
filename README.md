# Gym Tycoon

Handyspiel: Du erbst die heruntergekommene Muckibude deines Onkels und machst daraus das beste Gym der Stadt.
Pixel Art schräg von oben, Hochformat, Idle-Tycoon.

Status: **Planung** (Etappe E0).

## Inhalt

## Prototyp lokal öffnen

`prototypes/stil/index.html` im Browser öffnen. Ziehen zum Verschieben, zwei Finger oder Mausrad zum Zoomen,
auf Müll und kaputte Geräte tippen.
